# DevForge Roadmap

This roadmap is a guide, not a promise that every item will be implemented in one pass. Each feature should include tests, examples, and documentation.

## Phase 1 — Foundations
- [x] Python package structure and command-line entry point
- [x] Binary search and linear search
- [x] Stable merge sort
- [x] Unit tests for core algorithms
- [x] Input parsing and reusable validation helpers

## Phase 2 — Data structures
- [ ] Stack and queue abstractions
- [ ] Singly and doubly linked lists
- [ ] Hash map with collision handling
- [ ] Binary search tree and traversal algorithms
- [ ] Heap and priority queue

## Phase 3 — Developer utilities
- [ ] Structured logging helpers
- [ ] Configuration loading and validation
- [ ] File inventory and duplicate detection
- [ ] Safe batch file operations with dry-run mode
- [ ] JSON and CSV inspection tools

## Phase 4 — Quality and delivery
- [ ] Continuous integration on pull requests
- [ ] Static checks and formatting
- [ ] Coverage reporting
- [ ] Versioned releases and change log
- [ ] Usage examples and performance notes

## Definition of done

A feature is complete when its behavior is documented, its edge cases are tested, and its public interface is understandable without reading its implementation.
